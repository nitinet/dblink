# Fix Bug Prompt Template

## Bug description

Describe symptom, stack trace, and expected behavior.

## Reproduction

Provide failing test or minimal reproduction steps.

## Scope

List affected modules only.

## Constraints

- Apply minimal-risk fix.
- Preserve API behavior unless explicitly requested.

## Validation

- Repro test passes.
- Related tests still pass.

## Deliverables

- Code change
- Regression test
- Root-cause note
