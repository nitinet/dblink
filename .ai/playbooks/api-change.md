# API Change Playbook

This repository is a library; HTTP API endpoints are not implemented here.

Not found in current codebase.

For package API changes:
1. Define intended public API change.
2. Update exports in `src/index.ts` only if required.
3. Maintain backward compatibility when possible.
4. Add tests for new/changed public behavior.
5. Update README usage examples.
6. Run build and tests.
7. Publish release notes with migration guidance.
