# Refactoring Playbook

1. Identify module boundaries and current pain points.
2. Capture behavior with tests before refactor.
3. Refactor in small, reviewable steps.
4. Keep public API stable unless explicitly changing it.
5. Re-run tests after each logical step.
6. Validate build output and generated JS consistency.
7. Update docs if maintainability-related behavior is now clearer.
